# Lanzadores

Los lanzadores son opcionales. El comando canónico sigue siendo:

```bash
python app.py
```

## Valores predeterminados del lanzador Windows → WSL

- Distribución WSL: `Ubuntu-24.04`
- Proyecto: `~/projects/yue2-studio`
- Python: `~/venvs/yue2/bin/python`
- Puerto: `7860`

Pueden sobrescribirse con variables de entorno de Windows:

- `YUE2_STUDIO_WSL_DISTRO`
- `YUE2_STUDIO_WSL_PROJECT`
- `YUE2_STUDIO_WSL_PYTHON`
- `YUE2_STUDIO_PORT`

Los lanzadores públicos no contienen rutas personales.
